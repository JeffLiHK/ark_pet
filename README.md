# ArkPet 桌面寵物

ArkPet 是一款以《明日方舟》為主題的 Windows 桌面寵物。把喜歡的角色放到桌面，點一下聽台詞、看互動動畫，也可以讓幾隻小人一起陪你工作。首次下載角色資源後，平日可以離線使用。

## 下載與安裝

1. 到最新版本的下載頁選擇 `ArtPet-win-x64.zip`，適用於 64 位元 Windows。 [下載 ArkPet](https://github.com/JeffLiHK/ark_pet/releases/latest)
2. 將 ZIP 完整解壓縮，雙擊 `ArtPet.exe`。
3. 首次開啟時保持網路連線，等角色、立繪、字幕和日語配音下載完成，小人就會出現在桌面上。

## 桌面玩法

- **逗逗小人。** 點一下播放互動動畫，有配音的角色也會說話。按住左鍵可以拖動，右鍵可以轉身、置頂或隱藏。
- **替角色換裝。** 右鍵小人開啟衣櫃，搜尋喜歡的角色、預覽立繪，再選一套造型。
- **讓小人自在活動。** 開啟自由模式，小人會自己散步和休息。開啟物理模式，從半空放手時，小人會落在視窗上緣、工作列或螢幕底部。
- **讓幾隻小人一起陪你。** 從右鍵選單新增小人，每隻都可以各自換裝、移動和隱藏。
- **調整到喜歡的樣子。** 在設定中調整小人大小、描邊和陰影，也可以切換配音、字幕和音量。預設使用日語配音和繁體中文字幕，普通話配音可在「資源管理」下載。

後續版本會加入「我的小人」主介面，可切換專注情境、收藏喜歡的台詞、儲存常用的桌面配置，還能讓小人互動或拍一張透明背景的合照。

## 找回小人與更新

如果小人被隱藏了，可在 Windows 工作列右下角找到 **ArkPet** 圖示，右鍵選擇顯示。看不到圖示時，請先展開隱藏圖示。

想更新程式，可到「設定 → 更新」按「檢查程式更新」。首次下載角色資源若中斷，可到「設定 → 資源管理」按「更新全部模型」。

從 v1.7.0 或更早的版本升級時，請跟隨手動升級步驟，以保留原有的設定、角色和配音。 [舊版升級說明](https://github.com/JeffLiHK/ark_pet/releases/tag/v1.8.0#從-v170-或更早版本手動升級)

## 功能詳解

### 下載版已提供

- **點擊互動。** 用滑鼠左鍵點一下小人，就會播放互動動作。角色有已安裝的配音時，也會隨機說一句台詞，並按字幕設定顯示文字。
- **拖曳、轉身與置頂。** 按住左鍵，把小人拖到想放的位置，也可以拖到另一個螢幕。右鍵選「轉身」可反轉方向，開啟「置頂」可讓小人留在其他視窗上方。
- **顯示、隱藏與移回原位。** 右鍵小人可暫時隱藏。從工作列通知區的 **ArkPet** 圖示可找回小人、把主要小人移回主螢幕右下角，或選「結束程式」收起所有小人。
- **衣櫃。** 右鍵小人後選「衣櫃」，可搜尋角色名稱、按職業篩選，再查看立繪和造型預覽。首次使用部分造型時，需要稍等程式準備動畫。
- **新增及管理多隻小人。** 從小人的右鍵選單或通知區選「新增一隻小人」，可新增一隻相同造型的小人。每隻都能獨立換裝、拖曳和隱藏。通知區的「管理小人」可找回隱藏的小人，或移除後來新增的小人。
- **自由模式。** 在「設定 → 一般」開啟後，小人會依造型支援的動作，自行散步、發呆、坐下或睡覺。「散步速度」可調整走路快慢。
- **物理模式。** 在「設定 → 一般」開啟後，從半空放手的小人會落到視窗上緣、工作列或螢幕底部。也開啟自由模式時，小人可沿著支撐面走動，走出邊緣會繼續下落。
- **互動模式。** 在「設定 → 一般」關閉後，滑鼠可以直接點到小人後面的視窗。要恢復點擊和拖曳，可從通知區開啟設定，再開啟互動模式。
- **大小與動畫。** 「設定 → 一般」可調整小人的縮放大小、動畫幀率和待機動作切換前的循環次數。
- **描邊與陰影。** 在「設定 → 外觀」分別調整高亮描邊和陰影，讓小人在不同桌面背景上更容易看清楚。
- **配音、字幕與音量。** 在「設定 → 語音與字幕」可切換日語或普通話配音，選擇繁體中文、日文或關閉字幕。音量調到 0% 即可靜音。普通話配音需先在「資源管理」下載。
- **登入時啟動。** 在「設定 → 一般」開啟「登入 Windows 時啟動 ArkPet」，下次登入時小人就會自動出現。
- **資源管理。** 在「設定 → 資源管理」可更新角色模型、查看磁碟用量、按造型準備或刪除動畫，以及分別下載或刪除日語和普通話配音。之後再使用已刪除動畫的造型時，程式可重新準備動畫。
- **程式更新。** 在「設定 → 更新」可檢查新版，下載完成後重新啟動即可套用。角色模型與配音可在資源管理各自更新。

### 尚未在下載版推出

- **「我的小人」主介面。** 雙擊通知區的 **ArkPet** 圖示，或右鍵選「開啟主介面」，就能查看所有小人的角色、造型及顯示狀態。在同一處可換裝、複製小人、找回隱藏的小人，或直接開啟設定和資源管理。關閉主介面後，小人會繼續留在桌面。
- **桌面情境。** 「日常」沿用平時設定。「專注」暫停自動走動、桌面語音和字幕，小人仍可待機、拖曳和落下。「暫時隱藏」會一次收起所有小人，切回其他情境時，原先設為顯示的小人便會回來。
- **活動範圍。** 在小人詳情，可讓自由模式的走動限於目前螢幕、指定螢幕或指定螢幕的一角。手動拖曳仍可移到其他地方，小人在範圍外會暫停自動走動。可拖回去或按「移回活動範圍」恢復。指定螢幕中斷時，會暫用主螢幕。
- **動作預覽與語音試聽。** 在小人詳情可查看目前造型支援的動作，例如待機、行走、坐下或睡覺。也可選一句台詞，套用目前的配音、字幕與音量來試聽。預覽期間，桌面上的小人會照常活動。
- **語音收藏。** 在試聽或「最近播放」中收藏台詞，再按角色查看、重播或取消收藏。同一句台詞切換配音語言後仍會保留收藏。開啟「互動時優先播放收藏」後，點擊小人會優先播放目前配音可用的收藏台詞。
- **記住桌面配置。** 在「桌面配置」開啟後，下次啟動會自動恢復各隻小人的造型、位置、置頂、顯示偏好及活動範圍。這適合每天沿用上次離開時的桌面安排。
- **已儲存的小人配置。** 輸入名稱並按「儲存目前配置」，就能留住整組小人的數量、造型、位置、朝向與個別設定。例如可以各存一組工作和休息配置，之後按該組的「套用」即可切換。已儲存的配置在重開後仍可使用。
- **今日輪值。** 在「桌面配置」勾選候選造型並開啟輪值，每天第一次啟動時會從可用候選中替主要小人選一套。當天手動換裝後，再次開啟仍會使用手動選擇的造型。
- **小人之間的互動。** 在兩隻小人的詳情都開啟「允許小人互動」。拖曳其中一隻到另一隻附近再放手，符合條件的小人會轉向彼此，有互動動作的小人會播放一次。隱藏或正在互動的小人會略過。
- **桌面合照。** 勾選想入鏡的小人，調整各自的姿勢、位置和朝向，再按「匯出透明 PNG」選檔名和儲存位置。透明背景的圖片可以放到其他圖片或文件中，拍照時桌面上的小人會照常活動。
- **待機循環基準。** 「設定 → 一般」的待機循環設定改為基準次數。每段待機會在基準附近變動，偶爾也會連續播放同一個動作。
- **準備造型動畫的選項。** 「設定 → 一般」的「模型建構硬件加速」可加快準備新造型動畫。遇到相容問題時，可以關閉這個選項後再試。
