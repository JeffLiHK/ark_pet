# Art Pet 桌面框架原型

Art Pet 平時待在工作列附近，做呼吸和眨眼的待機動作。短按牠會跳一下，按住拖曳可以移位。桌面版沿用專案的繁中選單、右下角定位和青綠色調。現在用原創的「小芽」測試互動，原型完全離線、免登入，啟動即可見。後續角色與衣櫃依[既有產品需求](docs/prototype-plan.md)接入。

## 啟動與操作

在 Windows 的 PowerShell 打開專案根目錄。安裝 .NET 10 SDK `10.0.4xx` 後執行以下指令。

```powershell
dotnet run --project src/ArtPet.Windows/ArtPet.Windows.csproj -c Release
```

- 小芽預設在主螢幕工作區右下角，視窗為 160 DIP，離右邊及底部各 16 DIP，預設置頂。
- 用滑鼠主鍵短按小芽，或按住拖曳。右鍵選單可切換置頂或隱藏小芽。
- 右鍵點工作列通知區的 **Art Pet** 圖示，可顯示、隱藏、切換置頂、移回主螢幕右下角或結束。找不到圖示時，展開通知區的隱藏圖示。雙擊圖示也會顯示小芽。
- 位置、置頂與顯示狀態在當次執行期間有效。結束後重開會套用預設值。同一 Windows 登入工作階段只會執行一個實例。

## 第一個里程碑的驗收條件

1. 啟動後，小芽出現在主螢幕工作區右下角並持續待機。原本正在使用的視窗保有前景，工作列沒有小芽的視窗按鈕。
2. 點透明區域會操作下方視窗。短按角色會跳起並回到待機，反應中快速連點只播一次。按住移出原本輪廓再放開，角色會停在新位置並維持原本的前景視窗。
3. 置頂可開關。隱藏時停止動畫，從通知區可在目前位置顯示並恢復待機。執行「移回主螢幕右下角」也會叫回隱藏的小芽。
4. 通知區的「結束程式」移除視窗、圖示並結束程序。重複啟動只保留原有視窗和圖示。

## 視窗與滑鼠

桌面視窗沿用 C#／.NET 10 與 WPF，以 `WindowStyle=None`、`AllowsTransparency=true` 和透明底建立分層視窗。Windows 讓零 Alpha 像素的滑鼠事件穿透。`ShowActivated=false` 和 `WM_MOUSEACTIVATE` 回傳 `MA_NOACTIVATE`，讓角色接收點擊而保留目前的前景視窗。置頂交給 WPF `Topmost`。 [Win32 分層視窗](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features#layered-windows) · [滑鼠啟用訊息](https://learn.microsoft.com/en-us/windows/win32/inputdev/wm-mouseactivate)

主鍵按下後才啟動短時間的計時器，追蹤實體按鍵與游標。位移超過 Windows 的拖曳門檻後，用 `SetWindowPos` 在實體像素座標移動並保留前景。短按放開時再用 `WindowFromPoint` 確認命中角色。Per-Monitor V2 用於 DPI 切換，位置依螢幕工作區限制。 [程式架構](docs/architecture.md#桌面互動與動畫)

## 後續里程碑

1. **桌面框架。** 本次先做透明像素穿透和通知區復原入口，顯示變動時嘗試把小芽留在原螢幕工作區，原螢幕移除時回主螢幕。通知區可隨時手動叫回。小畫布動畫約每 50 ms 更新一次，隱藏即停止計時。
2. **素材與衣櫃。** 沿用本機 PNG 與角色清單方案，接入可使用的素材、正式角色和兩套造型。預先解碼影格，限制快取，量測實際素材的更新頻率和記憶體。 [素材格式](docs/architecture.md#角色素材與換裝)
3. **設定與復原。** 保存相對工作區的錨點、螢幕、大小、置頂和造型，測試重開、混合 DPI、拔除螢幕和解析度變更。若實測有讓整個角色都接受滑鼠穿透的需求，在這階段加入可從通知區解除的模式，並讓解除操作一併找回角色。整隻穿透時，通知區仍可控制顯示及退出。
4. **測試包與效能驗收。** 先輸出 `win-x64` 自包含資料夾，在 Windows 11 及 Windows 10 21H2 LTSC x64 驗收啟動、互動、恢復和資源使用，再評估安裝程式。 [發佈與效能門檻](docs/architecture.md#效能設計與發佈門檻) · [.NET 的 Windows 支援版本](https://learn.microsoft.com/en-us/dotnet/core/install/windows#supported-versions)

養成和工作提醒保留為後續產品方向。第一版以安靜陪伴為主。

## Windows 驗證紀錄

- **Windows 11 Pro，組建 26300，96 DPI。** Release 建置成功，實際用上面的指令啟動。確認原生視窗、預設右下角位置及置頂、第二次啟動沒有建立新視窗、關閉程式後回傳退出碼 0。
- **程式內測試。** 驗證 WPF 畫面有透明與不透明像素，待機畫面會變動，反應結束後回到待機。以程式呼叫互動處理驗證拖曳門檻及移動，以及通知區命令的隱藏停播、顯示、置頂、叫回和退出回呼。測試也以兩個原生視窗確認，關閉置頂後仍可把被遮住的小芽叫回。
- **待互動驗收。** 測試期間 Windows 處於鎖定狀態。實際桌面上的滑鼠穿透、短按、拖曳、前景保持和通知區點選仍待查驗。混合 DPI、實際拔除螢幕、變更解析度，以及 Windows 10 LTSC 測試包和正式素材的效能也安排在後續驗收。
