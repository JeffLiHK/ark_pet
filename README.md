# ArkPet 桌面寵物

ArkPet 是一款以《明日方舟》角色為主題的 Windows 桌面寵物。你可以讓喜歡的角色在桌面待機、散步或休息，點一下播放互動動畫，也可以一次擺放多隻小人。角色資源下載完成後，日常使用可離線進行。

## 桌面寵物功能

- **點擊與拖曳**。短按小人會播放互動動畫，有配音的角色也會播放台詞並顯示字幕。按住左鍵可拖曳，右鍵可轉身、切換置頂或隱藏。關閉「設定 → 一般 → 互動模式」可讓滑鼠穿透小人。
- **衣櫃**可搜尋角色名稱、按職業篩選，並預覽造型立繪和模型。右鍵小人即可開啟衣櫃。首次套用部分造型時，程式會生成動畫影格。
- **自由模式**讓有走路動畫的小人自行散步和休息，步速可調。開啟**物理模式**後，從半空放手的小人會落到視窗上緣、工作列或螢幕底部。兩種模式可同時開啟。
- **多隻小人可獨立換裝、拖曳和隱藏**。從小人右鍵選單或工作列通知區選「新增一隻小人」，再從通知區的「管理小人」找回或移除額外的小人。
- **配音與字幕**預設為日語配音和繁體中文字幕。在「設定 → 語音與字幕」可調整音量、切換日文字幕或關閉字幕。普通話配音可從「資源管理」下載後切換。 [語音與字幕說明](docs/hoolheyak-voice.md)
- **外觀與啟動選項**包括小人大小、動畫幀率、待機循環、描邊、陰影，以及登入 Windows 時自動啟動。

## 主介面與桌面配置

以下功能已加入 `main` 分支，目前可從原始碼建置使用。公開下載版 v1.8.0 提供上面的桌面寵物功能。 [v1.8.0 發佈頁](https://github.com/JeffLiHK/ark_pet/releases/tag/v1.8.0) · [原始碼建置說明](AGENTS.md#build-and-run)

雙擊工作列通知區的 **ArkPet** 圖示可開啟主介面。也可右鍵圖示，選「開啟主介面」。

- 在**我的小人**選擇卡片，可預覽動作、試聽語音，並為自由走動指定螢幕或角落。兩隻小人均開啟「允許小人互動」後，把其中一隻拖到另一隻附近再放手，即可觸發互動。
- **桌面情境**有「日常」、「專注」和「暫時隱藏」。專注會暫停自由走動和桌面語音，暫時隱藏會同時收起所有小人。
- **一鍵切換小人配置**。在「桌面配置」輸入名稱並按「儲存目前配置」，即可保存小人數量、角色與造型、位置、朝向、置頂、顯示狀態、活動範圍和互動偏好。每組配置都有自己的「套用」按鈕，重新啟動後仍可切換。
- 開啟**記住桌面配置**，下次啟動時便會恢復小人和位置。啟用**今日輪值**可在每天首次啟動時，從候選造型中為主要小人選一套。
- **語音收藏**可保存試聽或最近播放的台詞，方便重播，也可設定點擊小人時優先播放收藏。
- 在**桌面合照**選擇入鏡的小人，調整姿勢、位置和朝向，再匯出透明背景 PNG。

## 下載與安裝

1. 前往 [GitHub 最新版本](https://github.com/JeffLiHK/ark_pet/releases/latest)，在下載附件（Assets）選擇 `ArtPet-win-x64.zip`。發佈包適用於 Windows x64。下載附件及執行檔沿用原名。
2. 將整個 ZIP 解壓縮到想存放程式的資料夾，然後雙擊 `ArtPet.exe`。
3. 首次啟動時請保持網路連線。程式會自動下載角色模型、立繪、字幕及日語配音，完成後會在桌面顯示小人。資源就緒後，平日使用可離線進行。

若首次下載中斷，可從工作列通知區的 **ArkPet** 圖示開啟「設定 → 資源管理」，再按「更新全部模型」。若程式提示缺少 WebView2，請安裝 Runtime 後再試。 [Microsoft WebView2 下載頁](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section)

若找不到 ArkPet 圖示，請展開通知區的隱藏圖示。從圖示的右鍵選單可顯示或隱藏小人、移回主螢幕右下角、開啟設定或結束程式。

## 更新程式

在「設定 → 更新」按「檢查程式更新」。角色素材則在「設定 → 資源管理」按「更新全部模型」。

v1.7.0 或更早版本可能無法從改名後的倉庫下載程式更新、模型或配音。升級到支援新網址的版本時，請手動安裝一次。先關閉舊版，把新版 ZIP 解壓縮到新資料夾，再將舊版的 `local-data`、`assets` 和 `resource` 下的素材資料夾（如有）複製到新資料夾的對應位置，然後執行 `ArtPet.exe`。曾開啟登入時啟動的話，請在新版設定中關閉再重新啟用。之後可在程式內更新。 [舊版升級說明](https://github.com/JeffLiHK/ark_pet/releases/tag/v1.7.0)
