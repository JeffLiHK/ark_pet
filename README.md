# ArkPet 桌面寵物

ArkPet 是一款以《明日方舟》為主題的 Windows 桌面寵物。把喜歡的角色放到桌面，點一下聽台詞、看互動動畫，也可以讓幾隻小人一起陪你工作。首次下載角色資源後，平日可以離線使用。

## 下載與安裝

1. 到最新版本的下載頁選擇 `ArtPet-win-x64.zip`，適用於 64 位元 Windows。 [下載 ArkPet](https://github.com/JeffLiHK/ark_pet/releases/latest)
2. 將 ZIP 完整解壓縮，雙擊 `ArtPet.exe`。
3. 首次開啟時保持網路連線，等角色、立繪、字幕和日語配音下載完成，小人就會出現在桌面上。

## 桌面玩法

- **逗逗小人。** 點一下播放互動動畫，有配音的角色也會說話。按住左鍵可以拖動，右鍵可以轉身、置頂或隱藏。
- **替角色換裝。** 右鍵小人開啟衣櫃，搜尋喜歡的角色、預覽立繪，再選一套造型。
- **讓小人自在活動。** 開啟自由模式，小人會自己散步和休息。開啟物理模式，從半空放手時，小人會落在視窗上緣、工作列或螢幕底部。
- **讓幾隻小人一起陪你。** 從右鍵選單新增小人，每隻都可以各自換裝、移動和隱藏。
- **調整到喜歡的樣子。** 在設定中調整小人大小、描邊和陰影，也可以切換配音、字幕和音量。預設使用日語配音和繁體中文字幕，普通話配音可在「資源管理」下載。

後續版本會加入「我的小人」主介面，可切換專注情境、收藏喜歡的台詞、儲存常用的桌面配置，還能讓小人互動或拍一張透明背景的合照。

## 找回小人與更新

如果小人被隱藏了，可在 Windows 工作列右下角找到 **ArkPet** 圖示，右鍵選擇顯示。看不到圖示時，請先展開隱藏圖示。

想更新程式，可到「設定 → 更新」按「檢查程式更新」。首次下載角色資源若中斷，可到「設定 → 資源管理」按「更新全部模型」。

從 v1.7.0 或更早的版本升級時，請跟隨手動升級步驟，以保留原有的設定、角色和配音。 [舊版升級說明](https://github.com/JeffLiHK/ark_pet/releases/tag/v1.8.0#從-v170-或更早版本手動升級)
