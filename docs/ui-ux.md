# 桌面寵物 UI／UX 設計

霍爾海雅的 Q 版小人是主要畫面。平時只在桌角待機，摸摸、拖曳和換裝都從桌面直接操作。衣櫃和設定按需要打開。首版驗證預設造型與「歷世流風」。[Prototype 產品需求](prototype-plan.md) · [程式架構](architecture.md)

## 視覺方向

參考《明日方舟》首頁中低彩度的塊面、清楚的分隔線，以及用少量重點色標出操作狀態的做法。衣櫃採本專案的單欄構圖，使用石墨灰面板與青綠選取色，讓霍爾海雅的立繪成為畫面重心。圖示使用簡單的通用符號，按鈕以繁體中文標示。[明日方舟首頁介面參考](https://arknights.wiki.gg/wiki/Home_Screen/UI) · [官方「歷世流風」展示](https://www.youtube.com/watch?v=jKCdH0gqC-w)

- **配色。** 視窗底色 `#151B20`，圖卡 `#222B33`，滑過時 `#293640`，分隔線 `#566773`。主要文字 `#F2F5F7`，次要文字 `#B7C4CC`，使用中 `#72DDC3`，鍵盤焦點 `#C3D7F7`，需處理的狀態 `#FFCB8B`。
- **字體。** 繁中使用 Windows 的微軟正黑體 UI，英數可用 Segoe UI。角色名稱 20 DIP 半粗，造型名稱 15 DIP，選單及狀態文字 14 DIP。保留 Windows 標準標題列與關閉按鈕。
- **畫面層次。** 衣櫃以實色底、直角圖卡、1 DIP 細線和 16 DIP 內距呈現。已套用的造型以細邊框及「使用中」文字標示。鍵盤焦點用 2 DIP 描邊，可與使用中狀態同時顯示。

## 桌面小人與選單

- **小人。** 預設在主螢幕右下角，以 100% 大小循環播放待機動作。透明像素可點到下方的視窗。短按主鍵播放互動動作或微風特效，按住拖曳則移動。顯示小人或短按互動時保留原本的前景視窗。
- **小人右鍵選單。** 依序顯示「衣櫃…」、「大小」、「置頂」和「隱藏小人」。大小子選單標示目前套用的 75%、100% 或 125%。置頂以勾選狀態顯示，兩項設定都即時套用並保存。
- **工作列通知區域。** 素材就緒時，提供「顯示小人」或「隱藏小人」，並提供「衣櫃…」、「選擇素材資料夾…」及「結束程式」。衣櫃入口在小人隱藏時仍可使用。等待素材時，顯示「尚未選擇素材」或「角色素材無法載入」，保留選擇資料夾及結束程式。選單採 Windows 慣用樣式。

## 衣櫃

衣櫃使用一般視窗，預設內容寬約 400 DIP。小人可見時，衣櫃靠近小人且避開其位置。小人隱藏時，衣櫃開在上次所在的螢幕可用範圍。視窗保留在螢幕內，空間不足時捲動造型清單。衣櫃同時只開一個，已開啟時再次呼叫會帶回前景。

```text
┌ 衣櫃 ─────────────────────────────── × ┐
│ 霍爾海雅                               │
│ ┌────────┬───────────────────────────┐ │
│ │ 立繪   │ 預設造型          使用中  │ │
│ ├────────┼───────────────────────────┤ │
│ │ 立繪   │ 歷世流風                  │ │
│ └────────┴───────────────────────────┘ │
└────────────────────────────────────────┘
```

- **圖卡。** 每列左側預覽約 80 × 96 DIP，維持立繪比例。立繪無法讀取時，優先用該造型的待機首幀。右側顯示造型名稱與必要的狀態。草圖中的「立繪」表示圖片位置。
- **一鍵套用。** 整張可用圖卡都能點選。候選造型顯示「套用中…」，目前造型保留「使用中」並繼續播放。快速點選時以最後一次選擇為準，點回使用中的造型會取消待處理的選擇。成功時小人原地換裝，當前標記才移到新造型。
- **操作結果。** 必要的待機素材缺檔時在該列顯示「素材無法讀取」，保留目前造型。關閉衣櫃後，已發出的換裝可繼續完成，小人依當前顯示或隱藏狀態運作。從通知區替隱藏中的小人換裝，叫回時會看到新造型。
- **鍵盤。** 用 Tab 進入清單，方向鍵移動焦點，Enter 或空白鍵才套用，Esc 關閉衣櫃。造型名稱和狀態提供給 Windows 螢幕閱讀器，焦點、使用中與缺檔各有可辨識的呈現。

## 第一次啟動與復原

1. **準備素材。** 第一次啟動，從通知區選「選擇素材資料夾…」，用 Windows 資料夾選擇器選取霍爾海雅的資料夾。驗證及載入完成後，小人在主螢幕右下角顯示預設造型。使用者取消選取時，維持當前狀態。
2. **修復素材。** 主動選擇的資料夾無法載入時，顯示「找不到可用的角色素材。請選擇完整的素材資料夾。」並保留上次成功載入的角色。重新開啟程式時先載入上次的時裝，其次嘗試預設造型。兩者都無法載入時，從通知區重新選擇資料夾。
3. **保存偏好。** 大小、置頂、位置、造型和素材資料夾依產品需求保存及恢復。保存失敗時顯示「目前無法保存設定。重開後會恢復上次保存的設定。」使用者仍可繼續當前操作。[資料保存與設定](prototype-plan.md#資料保存與設定)

## 實作與驗收

- 衣櫃以共用的 WPF 樣式與圖卡範本呈現。造型名稱、排序和預覽取自素材清單，新增造型沿用圖卡與狀態樣式。
- 圖卡採靜態預覽，衣櫃開啟時載入縮圖，關閉時釋放。列表在互動或狀態改變時更新，待機動畫與背景換裝沿用既定的[效能門檻](architecture.md#效能設計與發佈門檻)。
- 驗證無素材時可從通知區完成首次載入，已選造型、載入中和缺檔能從文字辨識，連續點選後只套用最後選擇。小人或衣櫃收起後各自可重新開啟。
- 以鍵盤和 100%、125%、150% Windows 顯示比例驗證選單、衣櫃和關閉操作。一般文字目標至少 4.5:1，以所列深底、圖卡和滑過底色計算，最低的次要文字對比約 6.95:1。[W3C 文字對比參考](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
