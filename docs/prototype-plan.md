# 《明日方舟》桌面寵物 Prototype

第一個 Prototype 只用 **霍爾海雅**。她平時在 Windows 桌角做基建待機動作，點一下會回應，想換造型時可以一鍵換整套。先用她把這三件事做好，再加入其他幹員。

介面版型、操作流程及狀態提示見 [UI／UX 設計](ui-ux.md)。

## 第一版功能

- **點一下摸摸。** 滑鼠主鍵短按小人，播放一次基建互動動作，播完回到待機。若該套時裝沒有互動動作，就用短暫的微風特效回應。連點時只播放一個反應，按住拖曳則移動小人。
- **在桌角陪伴。** 素材就緒後首次出現在主螢幕右下角，循環播放基建待機動作。小人周圍的透明區域可以直接點到下方的視窗。
- **一鍵換整套。** 從小人的右鍵選單或工作列通知區域開啟衣櫃，透過立繪預覽選擇造型。素材載入完成後換上對應的 Q 版造型和動畫，小人留在原位。第一套用預設造型，第二套選「歷世流風」。PRTS 列出了預設造型的基建模型，「歷世流風」的基建檔案留待實際匯入時驗證。[PRTS 基建模型](https://prts.wiki/w/霍尔海雅/spine) · [官方時裝展示](https://www.youtube.com/watch?v=jKCdH0gqC-w)
- **隨時收起來。** 從右鍵選單暫時隱藏小人，並從工作列通知區域叫回。

## 素材與角色擴充

每套時裝從可使用的本機基建素材準備待機影格、可選的摸摸影格和衣櫃預覽圖。素材格式與載入方式見[程式架構](architecture.md)。待機素材讀取失敗時，衣櫃標示該造型暫不可用，保留目前穿著的時裝。摸摸動作缺失時可用微風作為回應，沒有立繪時可用待機畫面預覽。PRTS 可作為素材參考，其頁尾標明遊戲圖像和動畫的權利歸屬。[PRTS 幹員資料與素材聲明](https://prts.wiki/w/霍尔海雅)

桌面顯示、滑鼠互動和衣櫃共用同一套邏輯。等霍爾海雅通過驗收，再沿用相同的素材格式加入其他幹員，並補上角色選擇入口。

## 資料保存與設定

設定保存在目前 Windows 使用者的本機設定檔。設定變更完成後自動寫入，透過通知區結束程式時會等待最後一次保存。

### 使用者可調整的設定

- **桌面位置。** 拖曳小人，放開滑鼠後保存所在螢幕和相對於螢幕可用範圍的位置。首次使用放在主螢幕右下角。
- **顯示大小。** 從右鍵選單選擇 75%、100% 或 125%。選擇後立即套用並保存，預設為 100%。
- **視窗置頂。** 從右鍵選單開啟或關閉置頂。選擇後立即套用並保存，預設為開啟。
- **穿著時裝。** 從衣櫃選擇整套造型，成功換上後保存該時裝。第一次載入霍爾海雅時使用預設造型。
- **角色素材資料夾。** 從工作列通知區域選擇本機資料夾。素材驗證成功後保存資料夾路徑與角色識別資料。Prototype 用這個入口載入霍爾海雅。

### 重開後的行為

- **正常重開。** 讀取上次保存的角色素材與時裝，恢復螢幕、位置、大小和置頂。小人會顯示並從待機動作開始。隱藏只在當次執行生效。
- **螢幕配置變更。** 上次所在螢幕仍連接時，依目前的工作區調整位置，讓小人完整留在畫面內。該螢幕已拔除時，當次改在主螢幕右下角顯示。使用者再次拖曳後才保存新位置。
- **素材缺失。** 重開時先嘗試上次穿著的時裝，讀取失敗時改用可用的預設造型。首次尚未選擇素材、資料夾搬走，或上次的造型和預設造型皆無法載入時，保留通知區圖示，供使用者選擇素材資料夾。
- **設定讀取或保存失敗。** 設定檔讀取失敗時使用預設設定，原檔留待復原。保存失敗時提示使用者，當前操作仍可使用，下次重開會使用最近成功保存的設定。

## Prototype 驗收

測試案例、操作步驟和驗收紀錄見 [自動化測試與 Prototype 驗收](testing-and-acceptance.md)。

- 待機動畫能持續播放，短按有回應，拖曳能移動，透明區域能點到下方視窗。
- 兩套造型來回切換時，造型和動作一起更新，小人的位置保持穩定。
- 更改位置、大小、置頂和時裝後結束程式，重開時能從上次選擇的素材資料夾載入角色並恢復設定。先隱藏再結束程式，重開仍會顯示小人。
- 原先的螢幕拔除、素材搬移或設定檔損毀時，程式依上述規則恢復，通知區仍可使用。
- 正式測試包須符合[效能設計與發佈門檻](architecture.md#效能設計與發佈門檻)，包括動畫流暢度、互動延遲、CPU／GPU 使用率及記憶體用量。
