# ArkPet 主介面設計規格

「我的小人」是 ArkPet 的桌面管理入口。使用者打開視窗就能找到隱藏的小人、換裝、調整活動範圍，或在工作時切換到專注情境。[開啟離線互動原型](main-interface-preview.html) · [既有 UI／UX 設計](ui-ux.md)

互動原型可從檔案總管直接開啟。頁面上方可切換「第一階段／完整規劃」及素材狀態，這組控制只供預覽。原型以示範資料呈現資源下載、音訊播放、重新啟動、桌面互動與匯出結果。若專案目錄已有霍爾海雅素材，會取用本機立繪及影格，否則顯示隨專案提供的 ArkPet 圖示。

## 托盤與既有操作

- 左鍵雙擊托盤圖示開啟主視窗。再次雙擊帶同一視窗到前景，最小化時先還原。關閉主視窗後程式繼續在托盤運作。托盤右鍵提供「開啟主介面」、原有的小人顯示／隱藏與「結束程式」。
- 小人按既有編號排序。卡片顯示立繪、角色、造型和「顯示中／已隱藏／情境已隱藏」。「換裝」開啟該隻小人的衣櫃，成功後更新卡片與詳情，失敗時保留原造型。從托盤、衣櫃或桌面更新小人時，主視窗同步反映狀態。
- 「新增小人」複製選取的小人造型，新增後選取新卡片。更多選單提供「轉身」、「置頂」、「移回初始位置」。只有後來新增的小人有「移除」，移除後選取相鄰卡片。移回初始位置沿用既有行為，會顯示該隻小人。
- 「設定」開啟現有設定視窗。「資源管理」直接開啟同一視窗的資源管理分頁。沒有安裝造型時，以「尚未安裝角色資源」和「下載角色資源」取代列表，並停用新增。下載途中和失敗時顯示相應狀態，需重新啟動才載入新清單時提供明確提示。有素材但尚未選取造型時，顯示「選擇造型」入口。

## 佈局與操作

- **頂部**使用 Windows 標準標題列。內容列左側顯示 ArkPet，中間是「日常／專注／暫時隱藏」，右側是「設定」和「資源管理」。情境的選中狀態有文字、邊框及底色提示。
- **左側導覽**寬約 156 DIP。首階段有「我的小人」和「語音收藏」。「桌面配置」和「桌面合照」隨功能推出。今日輪值放在桌面配置，互動開關放在小人詳情。
- **主要區域**採約 308 DIP 的列表與彈性詳情欄。列表頂部放「新增小人」，卡片常用操作直接可見。詳情以角色動作預覽作為主畫面，其下依序放動作選擇、語音試聽、活動範圍與小人互動。
- **大小與縮放**以 1040 × 700 DIP 為雙欄參考尺寸，首次開啟限制在目前螢幕工作區內。寬度低於 900 DIP 時導覽移至頂部，列表與詳情改為單欄分頁，詳情提供「返回我的小人」。清單與詳情內容可捲動。
- **樣式與鍵盤**沿用石墨灰背景 `#151B20`、圖卡 `#222B33`、青綠 `#72DDC3` 和微軟正黑體 UI，正文 14 DIP，頁面標題 24 DIP。Tab 依視覺順序移動，Enter／空白鍵啟動按鈕，Esc 關閉選單或對話框並返回原焦點。狀態附文字，焦點使用 2 DIP 淺色邊框。

## 第一階段 · 日常使用

### 桌面情境

- **日常**依照現有設定活動，是啟動時的預設情境。
- **專注**暫停自由走動及桌面語音與字幕，保留拖曳、物理落下及待機動作。從主介面主動試聽時，依一般語音音量播放。離開專注後恢復使用者的自由模式和音量偏好。
- **暫時隱藏**統一收起所有桌面小人，但保留每隻的顯示偏好。此時仍可換裝或切換個別顯示偏好，詳情顯示「情境已隱藏」。切回日常或專注後，原先要求顯示的小人才會重現。

### 桌面活動範圍

在小人詳情選「目前螢幕」、「指定螢幕」或「指定螢幕的一角」。前者是預設，依小人所在螢幕計算工作區。「指定螢幕的一角」可選四角，活動區為對應的四分之一工作區。範圍限制自由模式的自動行走，手動拖放及物理落下依現有行為處理。小人離開選定範圍時暫停自動行走，拖回或按「移回活動範圍」後恢復。指定螢幕中斷時，提示目前使用主螢幕，並保留原選擇供螢幕接回時恢復。

### 試聽語音與預覽動作

在小人詳情選擇目前造型可用的動作，例如待機、坐下或睡覺。預覽在主視窗內播放，離開詳情時停止。試聽依照現有配音、字幕和音量設定，播放下一句會停止目前的試聽。素材還未建置或配音未安裝時，說明原因並提供資源管理入口。預覽使用獨立的播放狀態，桌面小人的位置、動作及姿勢照常運作。

### 語音收藏

從試聽或「最近播放」收藏一句台詞。收藏以角色 ID 和台詞 ID 辨認，同一句的日語及普通話共用收藏。使用者可按角色切換清單、重播或取消收藏。沒有收藏時提示可從最近播放或試聽加入。若目前語言缺少某句配音，收藏仍可查看，播放按鈕顯示不可用。開啟「互動時優先播放收藏」後，桌面短按互動從目前角色、目前語言可用的收藏隨機選取，清單為空時使用原有隨機播放。

## 第二階段 · 重開後恢復

### 記住桌面配置

「記住桌面配置」預設關閉，重開時使用既有啟動流程。在「桌面配置」開啟後，程式自動保存並還原每隻小人的造型、所在螢幕、相對工作區的腳底位置、置頂、顯示偏好及活動範圍。暫時隱藏只影響當次情境。螢幕不存在時回到主螢幕並把位置限制在工作區內。找不到原造型時依序嘗試該角色的預設造型和任一可用造型，並在桌面配置標示替換。沒有可用造型時顯示素材入口。

### 今日輪值

在桌面配置選入一個或以上已安裝造型，手動開啟今日輪值。每天以 Windows 本機日期為準，在當天第一次成功啟動時從可用候選取一套，套用到主要小人。若該日手動換裝，保留該選擇供同日再次啟動。其他小人照桌面配置恢復。候選都不可用時沿用已保存的主要小人造型，或使用既有啟動流程，並提示回到清單調整候選。

## 第三階段 · 多隻小人的玩法

### 小人之間的互動

在每隻小人詳情開啟「允許小人互動」，預設關閉。拖放結束後，如果最近的一隻小人可見、雙方都已開啟且目前可以互動，兩隻轉向彼此。有互動動畫的小人播放一次，再回到原先動作。同一次放手只觸發一組；小人已隱藏或正在播放短按互動時略過。

### 桌面合照

在「桌面合照」勾選入鏡的小人，調整每隻的位置、朝向和可用姿勢。可用拖放或位置控制移動，畫布以棋盤格提示透明背景。至少有一隻小人才能匯出透明 PNG。匯出前可改檔名及儲存位置，失敗時保留目前編排。拍攝區使用所選造型的影格，桌面上的小人照常活動。

## 驗收情境

- 雙擊托盤、最小化後再次雙擊，以及關閉再打開主介面。確認視窗只出現一個，關閉後仍可從托盤操作。
- 從已隱藏的小人開衣櫃，完成換裝、顯示並新增同造型小人。從桌面和托盤改變小人狀態時，主視窗同步更新。
- 檢查從「暫時隱藏」回到「日常」時原本隱藏的小人仍保持隱藏。確認專注開始及結束、拖出活動範圍及螢幕中斷時的結果。
- 驗證試聽、語音收藏、切換語言、刪除配音及收藏為空。確認資源未安裝或尚未套用造型時可找到下一步。
- 模擬重新啟動、主要小人輪值、同日手動換裝、停用保存，以及螢幕或造型缺失。確認觸發小人互動和匯出合照時，桌面其餘行為照常。
- 以一般和窄版視窗操作各頁，用鍵盤完成卡片管理、情境切換及對話框返回。實作 WPF 後於 100%、125% 及 150% Windows 顯示比例重驗。
